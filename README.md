**전장 하드웨어 개발 경험을 바탕으로 로봇 제어와 스마트팩토리 자동화를 실습하고 있습니다.**

전장팀에서 약 10개월간 하드웨어 개발 엔지니어로 근무하며 후방 모니터와 우레아 레벨 센서 개발에 참여했습니다. Altium Designer로 기존 회로와 PCB를 수정하고 부품 시험을 수행했습니다. 인텔 AI 융합 DX 과정에서는 PLC·서보·HMI 제어와 Indy7 로봇 이송, 머신비전을 실습했습니다. 앞으로 **디지털 트윈 프로젝트**, **머신비전 기반 로보틱스 융합 프로젝트**, **인텔 엣지 AI 실무 프로젝트**를 진행할 예정입니다.

## 주요 프로젝트

## 실습 기록

- **설비 제어** · Mitsubishi PLC로 센서 입력에 따른 순차제어를 구성하고, GP-Pro EX로 HMI 조작 화면을 만들었습니다. 전기 제어 회로 결선과 공압·유압 장비 조작도 실습했습니다.
- **협동로봇 제어** · Neuromeka Indy7으로 물체 이송과 반복 적재를 실습했습니다.
- **비전 AI·로봇 모방학습** · Intel Geti로 객체 탐지를 실습하고 이미지 분류와 영역 분할의 차이를 익혔습니다. LeRobot에서는 로봇 시연 데이터 수집과 정책 학습·추론 과정을 실습했습니다.
- **프로그래밍·데이터베이스** · C와 Python을 실습하고, PostgreSQL에서 테이블을 생성하고 SQL로 데이터를 조회했습니다.
